Practice rules

Eight decks are shuffled for each hand; the dealer stands on all 17s; a natural blackjack pays 3:2. Double-after-split is optional below because Rainbet’s public page does not clearly specify it. This simulator allows one split per original hand, gives split aces one card each, and permits doubling on any two cards (including split hands only when DAS is enabled).

Insurance, side bets, surrender, and resplitting are omitted. These are practice assumptions, not a claim that every rule exactly matches Rainbet. All balances and wagers are fake credits and reset when this page is reloaded.
